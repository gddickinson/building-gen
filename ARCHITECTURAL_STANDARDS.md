# Architectural Standards & Building Code Rules

Concrete, quantitative rules extracted from real building codes, architectural standards,
and historical building surveys. All values are codeable into the procedural generator.

Sources: UK Building Regulations (Approved Documents), US IRC (International Residential
Code), NDSS (Nationally Described Space Standard), NKBA Guidelines, Neufert Architects'
Data, Historic England conservation guides, Georgian Group technical notes.

## 2. Staircase Dimensions

### 2.1 UK Building Regulations (Approved Document K)

| Requirement                    | Private (domestic) | Shared/commercial |
|--------------------------------|--------------------|-------------------|
| Max riser height               | 220 mm             | 190 mm            |
| Min going (tread depth)        | 220 mm             | 250 mm            |
| Max pitch                      | 42°                | 38°               |
| Min headroom                   | 2.0 m              | 2.0 m             |
| Min headroom (loft conversion) | 1.9 m              | --                |

**2R + G formula:** Twice the rise plus the going must be between 550 mm and 700 mm.
Ideal target: 630 mm. Example: 190 mm rise + 250 mm going = 630 mm.

**Riser tolerance:** All risers in the same flight must be uniform within 5 mm.

**Typical domestic stair width:** 850-900 mm (no legal minimum for private stairs).

**Handrail height:** 900-1000 mm above pitch line.

**Maximum gap in balustrade:** 99 mm.

### 2.2 US IRC Stair Dimensions

| Requirement             | Value         | Metric   |
|-------------------------|---------------|----------|
| Min width (above handrail) | 36 in      | 0.914 m  |
| Min between dual handrails | 27 in      | 0.686 m  |
| Handrail height         | 34-38 in      | 0.86-0.97 m |
| Handrail projection     | up to 4.5 in  | 0.114 m  |
| Min headroom            | 6 ft 8 in     | 2.03 m   |
| Max riser               | 7.75 in       | 0.197 m  |
| Min tread               | 10 in         | 0.254 m  |

### 2.3 Staircase Footprint Calculator

For the generator, given a floor-to-floor height H:
- Number of risers = ceil(H / riser_height)
- Number of treads = risers - 1 (for a straight flight)
- Stairwell length = treads * going + landing_depth
- Typical example: H=2.8m, riser=0.19m -> 15 risers, 14 treads
  - Stairwell length = 14 * 0.25 + 1.0 = 4.5 m
  - Stairwell width = 0.9 m (single flight) or 2.0 m (U-shape, two flights side by side)

## 3. Room Connectivity Rules

### 3.1 Core Adjacency Rules (from real floor plan analysis)

**Circulation hierarchy (residential):**
1. Entrance hall / vestibule: connects to exterior and main circulation
2. Hallway / corridor: connects to all rooms on a floor (public circulation)
3. Landing: upper-floor equivalent of hallway, connects to stairwell
4. Stairwell: connects landings across floors

**Connection rules (must/should/must_not):**

| Room A          | Room B          | Rule     | Notes                                    |
|-----------------|-----------------|----------|------------------------------------------|
| entrance_hall   | front_parlour   | must     | Reception room visible from entry         |
| entrance_hall   | stairwell       | must     | Access to upper floors                    |
| entrance_hall   | dining_room     | should   | Or via hallway                            |
| dining_room     | kitchen         | must     | Food service route                        |
| kitchen         | scullery        | must     | Back-kitchen / wash-up                    |
| kitchen         | exterior        | should   | Service/delivery access                   |
| master_bedroom  | en_suite        | should   | Direct connection, no hallway             |
| master_bedroom  | dressing_room   | should   | Direct connection                         |
| bedroom         | landing         | must     | Via hallway, not through another room     |
| bathroom        | landing         | must     | Accessible from circulation               |
| bathroom        | bedroom         | must_not | Never pass through a bedroom to reach WC  |
| wc              | kitchen         | must_not | Not directly opening onto kitchen (UK reg)|
| wc              | dining_room     | must_not | Not directly opening onto dining          |
| servants_qtrs   | back_stair      | should   | Separate service circulation              |

### 3.2 Room-to-Hallway vs Direct Connection

**Must connect via hallway/landing (never directly to another room):**
- Bedrooms (except en-suite to master)
- WC / bathrooms (except en-suite)
- Study / library

**Can connect directly to each other:**
- Parlour <-> Dining room (via connecting/folding doors)
- Kitchen <-> Scullery
- Kitchen <-> Pantry
- Master bedroom <-> Dressing room
- Master bedroom <-> En-suite bathroom
- Entrance hall <-> Parlour

### 3.3 Plumbing Stacking (Vertical Alignment)

**Rule: Wet rooms should stack vertically across floors.**

- Bathroom above bathroom = ideal
- Bathroom above kitchen = acceptable (common in practice)
- Kitchen above kitchen = ideal
- Bathroom above living room = avoid (but possible with proper plumbing)

**Implementation:** Define a "wet zone" column in the building plan. All plumbing-
requiring rooms should fall within a 1-2m horizontal corridor of the plumbing stack.

## 4. Vertical Coherence Rules

### 4.1 Chimney/Fireplace Stacking

- Chimneys MUST align vertically through all floors
- Flue from ground floor gathers with upper floor flues in the same chimney breast
- Chimney breast width: typically 1.0-1.5 m
- Chimney breast depth: 0.3-0.45 m (projection into room)
- Party wall chimneys: back-to-back flues serving both houses
- Georgian rule: fireplaces on party walls (shared chimney stacks between terraced houses)
- Typical positions: centre of party wall, or flanking positions

### 4.2 Stairwell Alignment

- Stairwell MUST occupy the same plan position on every floor
- Stairwell is a vertical void cut through all floor plates
- Landing at each floor connects stairwell to that floor's rooms
- Georgian convention: staircase against party wall, behind entrance hall

### 4.3 Load-Bearing Wall Continuity

- Load-bearing walls MUST continue from foundation to roof
- A wall on an upper floor must have a supporting wall directly below it
- Interior load-bearing walls are typically perpendicular to floor joists
- Floor joists span the shorter dimension (front-to-back in narrow houses)
- Maximum unsupported span for timber joists: ~5 m (Georgian), ~6 m (modern)
- Party walls are always load-bearing

### 4.4 Floor Joist Direction

- Joists typically span the SHORTER dimension of the building
- In a narrow townhouse (6-8m wide, 10-14m deep), joists span front-to-back
- This means the party walls carry the floor load
- Internal walls parallel to joists are typically NOT load-bearing
- Internal walls perpendicular to joists CAN be load-bearing

## 5. Georgian Townhouse Specific Rules

### 5.1 Overall Dimensions

| Parameter                   | Typical Range    | Notes                        |
|-----------------------------|------------------|------------------------------|
| Frontage width              | 5.5-9.0 m       | 3-bay: 7-9m, 2-bay: 5.5-6.5m |
| Building depth              | 9.0-14.0 m      | Usually 1.5-2x the width    |
| Width:depth ratio           | 1:1.5 to 1:2    | Narrow and deep              |
| Number of storeys           | 3-5              | + basement, + attic          |
| Floor-to-floor height (principal) | 3.0-3.5 m | Ground & first floor        |
| Floor-to-floor height (upper)     | 2.7-3.0 m | Second floor and above      |
| Floor-to-floor height (attic)     | 2.2-2.5 m | Servants' quarters          |
| Basement floor-to-ceiling   | 2.4-2.7 m       | Kitchen/service level        |
| Party wall thickness        | 225-350 mm       | Min 9 inches (229 mm) brick  |

### 5.2 Plan Layout

**Standard arrangement: "One room front, one room back, passage and staircase to one side."**

```
Street facade (front)
+--------+--------+---+
| Front  | Entry  | S |
| Room   | Hall   | t |
| (parlour)       | a |
+--------+--------+ i |
| Back   | Passage| r |
| Room   |        | s |
| (dining)|       |   |
+--------+--------+---+
Garden/yard (rear)
```

- Staircase typically against one party wall
- Entrance hall runs from front door to staircase
- Front room: parlour/drawing room (faces street)
- Back room: dining room (faces garden)
- Side passage connects front to back
- Rooms can be opened up with folding doors between front and back rooms

### 5.3 Floor-by-Floor Arrangement

| Floor      | Typical Use                          | Ceiling Height | Decoration |
|------------|--------------------------------------|----------------|------------|
| Basement   | Kitchen, scullery, pantry, wine      | 2.4-2.7 m      | Plain      |
|            | cellar, laundry, servants' hall      |                |            |
| Ground     | Entrance hall, front parlour, back   | 3.0-3.5 m      | Fine       |
|            | dining room, study/library           |                |            |
| First      | Drawing room (main reception),       | 3.0-3.5 m      | Finest     |
|            | principal bedroom, dressing room     |                |            |
| Second     | Secondary bedrooms, nursery,         | 2.7-3.0 m      | Modest     |
|            | guest room, bathroom                 |                |            |
| Attic      | Servants' quarters, storage          | 2.2-2.5 m      | Plain      |

**Decoration gradient:** Finest rooms on the principal floor (ground/first), simplifying
as you ascend. This affects cornice depth, skirting height, door surround complexity.

### 5.5 Window Patterns (Fenestration)

**Window:wall ratio:** Georgian facades typically 25-35% glazing.

**Window proportions:** Height:width ratio of approximately 1.618:1 (golden ratio).
Typical sash window: 1.1m wide x 1.8m tall (6:10 panes, or 3:2 sashes).

**Window hierarchy by floor:**
- Ground floor: moderate height windows (often taller than wide, 6-over-6 panes)
- First floor (piano nobile): tallest windows, often full-height or with balcony
- Second floor: shorter windows, same width as first floor
- Attic: smallest/square windows, often within parapet or dormers

**Window spacing:** Regular rhythm, typically 3 or 5 bays (odd number for symmetry).
Pier width between windows: approximately equal to window width.

**Bay spacing (centre-to-centre):** Typically 2.0-3.0 m.

## 6. Natural Light Rules

### 6.1 Glazing Area Requirements

| Standard         | Min Glazing as % of Floor Area |
|------------------|-------------------------------|
| US IRC (R303)    | 8% of floor area              |
| General rule     | 10% of floor area (1:10)      |
| NYC code         | 10% of floor area             |

### 6.2 Room Depth from Window

**Rule of thumb: Maximum room depth = 1.5 to 2.0 x window head height.**

| Window Head Height | Adequate Depth (1.5x) | Max Depth (2.0x) | Dim Depth (3.5x) |
|--------------------|-----------------------|-------------------|-------------------|
| 2.1 m              | 3.15 m                | 4.2 m             | 7.35 m            |
| 2.4 m              | 3.6 m                 | 4.8 m             | 8.4 m             |
| 2.7 m              | 4.05 m                | 5.4 m             | 9.45 m            |
| 3.0 m              | 4.5 m                 | 6.0 m             | 10.5 m            |

**NYC code limit:** Habitable room depth shall not exceed 30 ft (9.14 m) from window.

**For generator:** Room depth should not exceed 2.0 x window_head_height for rooms
with windows on one wall only. Rooms with windows on two opposing walls can be
up to 4.0 x window_head_height.

## 9. Codeable Rules Summary

Below are the rules distilled into constraint-check pseudocode for the generator.

### Room Size Validation
```
for each room:
    assert room.area >= ROOM_CONSTRAINTS[room.type].min_area
    assert room.min_dimension >= ROOM_CONSTRAINTS[room.type].min_width
    assert room.aspect_ratio <= ROOM_CONSTRAINTS[room.type].max_depth_ratio
    assert room.ceiling_height >= 2.3  # NDSS minimum
```

### Daylight Validation
```
for each habitable room with exterior wall:
    window_area = sum(w.area for w in room.windows)
    assert window_area >= 0.08 * room.floor_area  # IRC 8% rule
    if room.windows_on_one_wall_only:
        assert room.depth <= 2.0 * window_head_height
```

### Staircase Validation
```
for each staircase:
    assert riser_height <= 0.220  # UK max
    assert going >= 0.220         # UK min
    assert 0.550 <= (2 * riser + going) <= 0.700  # 2R+G formula
    assert pitch_angle <= 42      # degrees
    assert headroom >= 2.0        # metres
```

### Vertical Coherence Validation
```
for each floor f > 0:
    # Stairwell alignment
    assert stairwell[f].position == stairwell[f-1].position

    # Chimney alignment
    for chimney in chimneys:
        assert chimney[f].position == chimney[f-1].position

    # Load-bearing wall continuity
    for wall in load_bearing_walls[f]:
        assert exists wall_below in load_bearing_walls[f-1]
            where wall_below.overlaps(wall)

    # Plumbing stacking
    for wet_room in wet_rooms[f]:
        assert distance_to_plumbing_stack(wet_room) <= 2.0  # metres
```

### Room Connectivity Validation
```
for each bedroom:
    assert bedroom.connects_to(hallway_or_landing)
    assert not bedroom.connects_to(another_bedroom)  # no pass-through

for each bathroom:
    assert bathroom.connects_to(hallway_or_landing) or
           bathroom.connects_to(master_bedroom)  # en-suite exception

for each wc:
    assert not wc.opens_directly_onto(kitchen)
    assert not wc.opens_directly_onto(dining_room)

for each kitchen:
    assert kitchen.connects_to(dining_room) or
           kitchen.connects_to(hallway_connecting_to_dining)
```

### Georgian Facade Validation
```
for georgian building:
    assert 0.25 <= window_wall_ratio <= 0.35
    assert window_height / window_width ~= 1.618  # golden ratio
    assert num_bays in [2, 3, 5]  # odd preferred
    assert pier_width >= window_width * 0.8  # roughly equal
    assert floor_heights decrease upward:
        ground >= first >= second >= attic
```
